Claude desktop app : Chat, Cowork, Code

⏱ Lecture : 6 min📚 Leçon : 6 min🎯 Choisir le bon mode
L'essentiel en une phrase : l'application de bureau offre 3 modes — Chat pour échanger, Cowork pour confier un objectif complet à un agent, Code pour construire du logiciel — et le bon choix dépend de l'ampleur et de la nature du travail.

Les 5 thèmes clés

Thème 1

Les 3 modes en un coup d'œil

💬 ChatQuestions, brainstorming, rédaction, aller-retour sur un problème. Le Claude de claude.ai, avec des atouts « natifs » en plus.Ex. : structurer un plan de présentation.
🤝 CoworkUn agent : tu donnes un objectif, tu le relies à tes outils, il fait le travail de bout en bout.Ex. : une veille concurrentielle complète, avec sources.
💻 CodeConstruire du logiciel : écrire, tester et déployer du code.Ex. : faire évoluer ton site de fiches sur GitHub.
À retenirCowork et Code tournent sur le même moteur (Claude Code) : ils travaillent en autonomie, lancent des sous-agents et tiennent des tâches longues.
Thème 2

Chat : les atouts du bureau

  • Accès rapide : double appui sur Option (Mac) → une petite fenêtre Claude par-dessus ton travail.
  • Captures et partage de fenêtre : Claude voit ce que tu vois (Mac).
  • Dictée : parler plutôt que taper (Mac).
  • Connecteurs de bureau : relier des outils locaux.
ExempleTu ouvres un tableau de bord Airtable inconnu : capture de la fenêtre + « que signifient ces indicateurs ? », sans quitter l'écran.
Thème 3

Code : construire du logiciel

  • Lit, écrit et modifie le code, lance des commandes ; diffs visuels, terminal intégré, git pour revenir en arrière.
  • Local : un dossier de ton ordinateur, aperçu dans le navigateur. Remote : un dépôt GitHub dans le cloud, la session continue même app fermée.
  • 3 niveaux d'autonomie : Ask valide chaque changement · Code applique, demande avant les commandes · Plan présente sa stratégie d'abord.
Exemple vécuAjouter une fiche à ton site, mettre à jour data.js et faire le commit sur GitHub : c'est exactement un travail « Remote ».
Thème 4

Cowork : confier un vrai chantier

Pour le travail qui demande un vrai effort : rassembler plusieurs sources, leur donner du sens, livrer un résultat fini. Claude pose d'abord quelques questions (périmètre, format, contraintes), propose un plan visible, puis avance ; on peut lancer plusieurs tâches en parallèle.

📁 Accès dossierLit un dossier de ton ordinateur et y enregistre le résultat.
⏰ Tâches planifiéesUn travail récurrent (briefing du matin, bilan hebdo) lancé automatiquement.
🧩 Sous-agentsDécoupe une grosse tâche en parties traitées en parallèle.
📱 DispatchContinuer depuis le téléphone, ordinateur allumé et app ouverte.
🗂 ProjetsEspaces dédiés avec fichiers, instructions et mémoire, stockés en local.
🌐 NavigationAvec Claude in Chrome : visiter des sites, relever des prix, extraire des données.
🖱 Computer useUtilise l'ordinateur comme toi ; ordre de priorité : connecteurs → Chrome → écran. Autorisation demandée par app.
🔌 PluginsAjoutent des capacités : données financières, base interne, conformité.
🔒 Environnement protégéAccès limité aux seuls dossiers que tu partages.
Exemples d'usageLire 50 documents de projet et en tirer une note de synthèse · comparer 10 outils no-code avec leurs prix et sources · préparer chaque matin un point sur tes candidatures en cours.
Thème 5

Choisir le bon mode

Si tu veux…ModePourquoi
Poser une question, réfléchir à voix haute, rédigerChatÉchange rapide, aller-retour
Un livrable fini à partir de nombreuses sourcesCoworkPlan, sous-agents, accès aux dossiers et outils
Une tâche qui revient chaque jour ou chaque semaineCoworkTâches planifiées
Créer, corriger ou déployer du codeCodeDiffs, terminal, git

ℹ️ Cowork et Code sont proposés sur les offres Pro, Max, Team et Enterprise ; certaines fonctions (computer use, raccourcis) sont en aperçu ou réservées au Mac. Les noms et l'interface évoluent vite : vérifie la version à jour.

Réflexion personnelle

Quel mode pour mes tâches habituelles ?

  • Chat : préparer une lettre de motivation, comprendre une notion de cours.
  • Cowork : analyser 20 offres d'alternance et sortir un tableau comparatif sourcé ; un point quotidien sur mes candidatures.
  • Code : faire évoluer le site de fiches Claude 101 ou mes fiches d'arabe sur GitHub Pages.
